# AgroIA

Agente conversacional para apoyo al cultivo del aguacate.

Proyecto académico (Ingeniería en Sistemas Computacionales — TecNM Jiquilpan).
Metodología Scrum, gestión en Jira. Repositorio monorepo.

## Estructura

- `svc-agente/` — Microservicio del agente conversacional (LangChain + FastAPI).
- `svc-gestion/` — (Entrega 2) Backend de gestión con Django/DRF.
- `svc-ingesta/` — (Entrega 4) Pipeline de ingesta para RAG.

## Entrega 1

El agente mínimo vive en `svc-agente/`. Consulta su README para instalar y ejecutar.
